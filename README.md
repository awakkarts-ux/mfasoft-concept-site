# MFASOFT — концепт главной (desktop)

Self-initiated концепт редизайна сайта mfasoft.ru для портфолио. Не официальный сайт.

- `index.html` — главная v2 «Смягчение» (только десктоп, вёрстка в rem, во всю ширину).
- `v1.html` — первая версия каркаса.
- `img/` — 3D-рендеры v3 (Blender), `shots/` — скриншоты.
- `SLOTS.md` — слоты под 3D-графику.

Открыть: скачать репозиторий и открыть `index.html` в браузере (нужен интернет для шрифта Golos Text).
Кнопка «Слоты 3D» слева внизу показывает места под графику.

Исходники проекта (аудит, бриф, стиль-гайд, 3D-сцены) — в репозитории `mfasoft-redesign`.
